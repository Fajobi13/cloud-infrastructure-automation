# Cloud Infrastructure Automation

This project demonstrates automated provisioning and configuration of cloud infrastructure using **Terraform** and **Ansible**. It focuses on enabling scalable, secure, and cost-efficient multi-cloud solutions.

## Features
- **Infrastructure as Code (IaC)**: Provisioned AWS resources such as EC2, RDS, and VPC using Terraform.
- **Configuration Management**: Used Ansible to configure servers and deploy applications.
- **Scalability**: Designed for multi-cloud deployments, ensuring high availability.
- **Security**: Configured secure environments with IAM roles, security groups, and VPCs.

## Technologies Used
- Terraform
- Ansible
- AWS (EC2, S3, RDS, IAM, VPC)
- Multi-Cloud Integration
